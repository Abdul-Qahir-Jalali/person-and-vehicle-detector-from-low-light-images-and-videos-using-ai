Introduction
3
Object detection is a fundamental task in computer vision that identifies                           and localizes objects in images or videos . It is widely used in:
Autonomous vehicles
Traffic monitoring
Surveillance systems
Smart city applications
However, detection accuracy decreases significantly in adverse weather conditions such as low light, rain, and fog. This project aims to develop a robust object detection system that performs effectively in challenging environments.
Background & Literature Review
4
Many researchers have used deep learning models for object detection:
R-CNN family models
SSD (Single Shot Detector)
YOLO (You Only Look Once)
Recent studies show that  YOLO provides real-time detection Performance drops in low visibility conditions Image enhancement techniques improve detection accuracy However, limited work focuses specifically on robust detection under low light, rain, and fog conditions . This project builds upon existing research and improves detection reliability in adverse environments.
Problem Statement
5
Most existing object detection systems perform well in normal lighting conditions. But they face challenges such as:
Reduced visibility
Noise in images
Blurred objects Low contrast
Therefore, there is a need to design a system that can accurately detect objects in adverse weather conditions.
Project Objectives
6
The main objectives of this project are:
To develop a robust object detection systemTo enhance low-quality images before detection
To implement YOLO-based deep learning model
To evaluate performance using standard metrics
To integrate the system into a web-based application

Conclusion
13
This project proposes the development of a robust object detection system capable of performing effectively under adverse weather conditions such as low light, rain, and fog. Traditional detection models show significant performance degradation in such environments, which limits their real-world applicability.
By integrating image enhancement techniques with a YOLO-based deep learning model, the system aims to improve visibility and detection accuracy simultaneously. The proposed modular architecture ensures scalability, flexibility, and ease of deployment.
Overall, this research contributes toward building more reliable and weather-resilient AI systems for real-world applications such as smart surveillance and intelligent transportation systems.
